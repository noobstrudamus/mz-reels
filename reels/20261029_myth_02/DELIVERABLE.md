## Caption
More rules on a certificate doesn't always mean more lab tests.
Under 16 CFR 1110.11(d), the certificate still lists each applicable rule separately. But certifiers aren't required to run the same third party test on a sample more than once when one rule references or fully incorporates another with the same requirement.
If a lab quote repeats the same test for overlapping rules, it's fair to ask why.
